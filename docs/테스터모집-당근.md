# 당근 모집 글 + 대면 미팅 준비 (2026-08-06)

목적: **3~5명을 직접 만나 쓰는 걸 관찰한다.** 설문이 아니라 관찰이 목적이다.
지금 필요한 답은 "좋았나요?"가 아니라 "어디서 멈추는가"다.

---

## 1. 당근 글 초안

> 당근 정책상 노골적인 홍보는 제한된다. 판매글이 아니라 **동네생활 "같이해요"** 성격으로 쓴다.
> 무료·모집이라는 말보다 "만들어드린다 / 봐주실 분"이 자연스럽다.

### 최종본 (유근님 글 + 보강)

```
온라인으로 상품 파시는 분, AI 상세페이지 무료로 만들어보실 분 !!

안녕하세요. AI로 상세페이지 만들어주는 프로그램을 만들고 있는 사람입니다.
저도 온라인으로 물건 팔던 사람이라, 상세페이지에서 막히는 답답함을 알아서 만들게 됐어요.

오픈 전이라, 실제로 파시는 분들의 피드백을 받아보려고 합니다.
상세페이지를 직접 만들어보셨거나 다른 AI상세페이지 프로그램을 사용해보셨거나, 
어떤 게 잘 팔리는지 감이 있으신 분이면 좋겠습니다.

▪︎ 무엇을: 꼭! 현재 파시는 상품으로 직접 만들어보시면 됩니다
▪︎ 어디서: 광교 근처, 장소 대여해서 만나려고 합니다 (추후 협의)
▪︎ 언제: 8월 O일(O) / O일(O) 중 편하신 시간으로 맞춰요
▪︎ 얼마나: 1시간 정도
▪︎ 비용: 없습니다. 결과물은 그대로 쓰셔도 됩니다
▪︎ 준비물: 노트북 / 구글 또는 카카오 계정 / 파시는 상품 사진 2~3장과 상품 정보
▪︎ 부탁: 쓰시면서 불편한 점 그대로 말씀해주세요~!!

3분만 모십니다. 관심 있으시면 채팅으로
"어떤 상품을 어디서 파시는지" 한 줄만 남겨주세요.

※ 동종업계·개발 목적의 신청은 정중히 사양합니다.
```

**보강한 것과 이유**
| 추가 | 왜 |
|---|---|
| "저도 온라인으로 물건 팔던 사람이라…" | 유근님의 유일한 차별점. 이 한 줄이 있고 없고가 신청률을 가른다 |
| 날짜 후보 | 날짜가 없으면 "언제요?"를 묻느라 한 번 더 오가고, 그 사이에 마음이 식는다 |
| 준비물에 계정·상품 정보 | 현장에서 가입하고 정보 입력하다 30분을 쓰면 정작 볼 걸 못 본다 |
| "상세페이지 이해도 높으신 분" → 문장 완성 | 원문은 문장이 끊겨 있었다 |

**법적 경고 문구에 대해**
원문의 강한 버전(기능 복제·법적 조치)은 그대로 쓰셔도 됩니다. 다만 당근 글에서는
방어적으로 읽혀 진짜 셀러도 위축시킬 수 있어, 위 최종본에는 한 줄로 줄여뒀습니다.
어차피 경쟁사가 마음먹고 오면 저 문구로 못 막고, 대신 **채팅 스크리닝**(뭘 어디서 파는지)에서
대부분 걸러집니다. 강하게 가고 싶으시면 원문 두 줄을 그대로 붙이시면 됩니다.

### B안 — 짧은 버전 (동네생활용)

```
상세페이지 만들어드릴 분 3분 찾습니다

상세페이지 만들어주는 프로그램을 혼자 만들고 있습니다.
오픈 전이라 실제로 파시는 분 몇 분께 써보게 하고 피드백을 받으려고 해요.

파시는 상품으로 그 자리에서 만들어드리고, 결과물은 그냥 쓰셔도 됩니다.
30~40분, 카페에서, 비용 없습니다.

채팅 주실 때 "어떤 상품을 어디서 파시는지" 한 줄 부탁드려요.
```

### 쓰기 전 체크
- [ ] `OO역`을 실제 장소로 바꾼다 — **공개된 카페**로 정한다(안전·상대 부담 모두)
- [ ] 링크(flik.kr)는 넣지 않는다 — 광고로 읽히고 당근에서 제재 사유가 된다
- [ ] "무료"를 제목에 반복하지 않는다 — 체험단 광고처럼 보인다
- [ ] 같은 글을 여러 동네에 도배하지 않는다

## 2. 신청자 거르기

무료라서 파는 게 없는 사람도 온다. **채팅 한 줄로 거른다.**

받을 답: "스마트스토어에서 강아지 수제간식 팔아요", "인스타로 액세서리 팔아요"

| 이런 답이면 | 판단 |
|---|---|
| 판매 채널 + 상품이 구체적 | ✅ 만난다 |
| "곧 시작하려고요" | 🟡 1명까지만 — 처음 쓰는 사람 관점이 필요하다 |
| "그냥 궁금해서요" | ⛔ 정중히 사양 |

만나기 전 요청: **상품 사진 2~3장과 상품 설명을 미리 보내달라고 한다.**
현장에서 정보 입력에 20분을 쓰면 정작 볼 걸 못 본다.

## 3. 준비물

- [ ] 노트북 (셀러가 직접 만지게 할 것 — 유근님이 대신 치면 아무것도 안 보인다)
- [ ] ⚠️**가입은 구글로 안내한다** (2026-08-06~ 카카오 이메일 동의항목 심사 대기 중)
      심사가 승인되면 카카오 계정의 식별자가 `kakao:12345`에서 이메일로 바뀐다.
      대기 중에 카카오로 가입한 사람은 승인 후 재로그인 시 **다른 계정으로 잡혀
      크레딧·작업 기록이 분리된다**(lib/authToken.ts: 이메일 우선, 없으면 provider:sub).
      승인 전까지는 구글로 받고, 이미 카카오로 가입한 분이 있으면 승인 후
      새 이메일 계정에 크레딧을 다시 지급해 주면 된다.
- [ ] 테스터 계정에 크레딧 미리 지급 (아래)
- [ ] 녹음 or 메모지 — 기억은 반드시 왜곡된다
- [ ] 결과물 전달 방법 (다운로드 → 이메일/카톡)

### 크레딧 지급 방법

> ⚠️**순서가 중요하다 — 가입을 먼저 시키고, 그다음에 준다.**
> 크레딧을 먼저 넣어두면 계정에 잔액이 있는 것으로 보여 **가입 축하 10크레딧이 안 들어간다**
> (`getOrCreateBalance`가 잔액 0일 때만 지급). 순서만 지키면 10 + 지급분이 다 들어간다.

**1단계 — 테스터가 가입** (미팅 자리에서)
flik.kr → 무료로 시작하기 → 구글 또는 카카오 로그인.
**가입에 쓴 이메일을 정확히 확인한다**(카카오 계정 이메일이 평소 쓰는 것과 다를 수 있다).

**2단계 — 유근님 노트북에서 관리자로 로그인**
같은 브라우저일 필요는 없다. flik.kr에 **hanmeiligo1@gmail.com**으로 로그인돼 있으면 된다.
(관리자 판단은 `ADMIN_EMAILS` 환경변수 기준 — 이 계정만 지급 API를 쓸 수 있다)

**3단계 — 개발자 도구 콘솔 열기**
크롬에서 `⌥⌘I`(맥) 또는 우클릭 → **검사** → 상단 **Console** 탭.

**4단계 — 붙여넣고 Enter**
```js
fetch('/api/admin/grant-credits', {
  method: 'POST', headers: {'Content-Type':'application/json'},
  body: JSON.stringify({ email: '테스터가가입한이메일@gmail.com', amount: 60, note: '대면테스트' })
}).then(r => r.json()).then(console.log)
```

> 크롬이 `경고: 붙여넣기 금지`를 띄우면, 콘솔에 **allow pasting** 을 타이핑하고 Enter를 친 뒤
> 다시 붙여넣는다(크롬의 사기 방지 기능이라 정상 동작이다).

**5단계 — 결과 확인**
`{ok: true, balance: 70, message: "…지급했어요. 현재 잔액 70."}` 이 나오면 끝.
테스터 화면에서 새로고침하면 크레딧이 올라가 있다.

**알아둘 것**
- 60크레딧 ≈ 블로그형 8섹션 6장. 미팅 중 여러 번 시도하기 충분하다.
- 같은 사람·같은 양·같은 사유는 **하루 1회만** 들어간다(중복 클릭 방어). 더 주려면 `note`를 바꾼다.
- 만료 없음 — 미팅 뒤에도 계속 쓸 수 있다.
- 상한 300. 지급 이력은 원장에 남아 셀러의 '크레딧 사용 내역'에도 정상 표시된다.

## 4. 미팅 진행 (30~40분)

### 규칙 하나: 말을 걸지 않는다
도와주고 싶은 걸 참는다. **설명해주는 순간 그 화면의 문제는 안 보이게 된다.**
막혀서 3초 이상 멈추면 그게 발견이다. 메모하고, 계속 두고 본다.
정말 못 넘어갈 때만 "지금 뭘 찾고 계세요?"라고 묻는다(답을 주지 말고 되묻는다).

### 순서
| 시간 | 할 일 |
|---|---|
| 0~5분 | 인사 + "오늘은 제가 안 도와드리고 지켜볼 거예요"라고 미리 양해 |
| 5~10분 | 뭘 파는지, 지금 상세페이지는 어떻게 만드는지 듣기 |
| 10~30분 | **직접 만들게 한다.** 시작 화면부터 끝까지. 유근님은 관찰만 |
| 30~40분 | 결과물 같이 보기 + 아래 질문 |

### 마지막 질문 (이것만)
1. **"이거 지금 쓰시는 방법이랑 비교하면 어떠세요?"** — 대안 대비 가치
2. **"이 결과물, 스토어에 그대로 올리실 수 있어요?"** — 올릴 수 없다면 이유가 곧 할 일
3. **"얼마면 쓰시겠어요?"** 먼저 묻지 말고, 상대가 가격을 물으면 그때 되묻는다
4. **"제일 답답했던 순간이 언제였어요?"**

⛔ 묻지 말 것: "좋으셨어요?", "쓸 만하죠?" — 앞에 사람 두고 나쁘다고 말할 사람은 없다.
